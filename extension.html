DyslexiaAway: your settings on every websiteDyslexiaAway: tus ajustes en todas las páginas web

A free, open-source browser extension that changes the font, letter spacing, word spacing and line height of the sites you visit. It has exactly the controls this site helps you test — and not much else, which is why we like it. Una extensión de navegador gratuita y de código abierto que cambia la fuente, el espacio entre letras, el espacio entre palabras y el interlineado de las páginas que visitas. Tiene justo los controles que este sitio te ayuda a probar, y poco más, y por eso nos gusta.

Set it up in 5 minutesConfigúralo en 5 minutos

  1. Install it from the store for your browser (buttons above). In Chrome, click the puzzle-piece icon and pin DyslexiaAway so it is always visible.
  2. Open a normal website (any news site or Wikipedia). It cannot change the browser’s own pages, such as the new-tab page or the extension store.
  3. Click the DyslexiaAway icon and switch it on with the toggle at the top.
  4. Font: choose it from the menu. For Verdana or Arial, choose Custom and type the font name exactly.
  5. Letter Spacing, Word Spacing, Line Height: drag each slider until the number matches your value in the box. For fine control, click a slider and use the arrow keys.
  6. Text size: DyslexiaAway does not change size, so set it in the browser:
    • Chrome: Settings › Appearance › Font size, or “Customize fonts” for an exact number.
    • Edge: Settings › Appearance › Fonts.
    • Firefox: Settings › General › Fonts › Size.
    • Any browser: zoom with Ctrl/⌘ and +.
  7. If a site looks broken (icons turning into letters, overlapping text), tick Exclude site for that site only.
  1. Instálala desde la tienda de tu navegador (botones de arriba). En Chrome, haz clic en el ícono de la pieza de rompecabezas y fija DyslexiaAway para tenerla siempre a mano.
  2. Abre una página web normal (un diario o Wikipedia). No puede cambiar las páginas propias del navegador, como la pestaña nueva o la tienda de extensiones.
  3. Haz clic en el ícono de DyslexiaAway y actívala con el interruptor de arriba.
  4. Fuente: elígela en el menú. Para Verdana o Arial, elige Personalizada y escribe el nombre exacto de la fuente.
  5. Espaciado letras, Espaciado palabras, Altura línea: mueve cada control hasta que el número coincida con tu valor del recuadro. Para afinar, haz clic en el control y usa las flechas del teclado.
  6. Tamaño de letra: DyslexiaAway no cambia el tamaño, así que ajústalo en el navegador:
    • Chrome: Configuración › Apariencia › Tamaño de fuente, o “Personalizar fuentes” para un número exacto.
    • Edge: Configuración › Apariencia › Fuentes.
    • Firefox: Ajustes › General › Tipografías › Tamaño.
    • Cualquier navegador: zoom con Ctrl/⌘ y +.
  7. Si una página se ve rara (íconos convertidos en letras, texto encimado), marca Excluir sitio solo para esa página.

Values use the same unit as the extension (em, relative to text size), so they copy across exactly and keep their proportions if you change the size. Los valores usan la misma unidad que la extensión (em, relativa al tamaño de letra), así que se copian tal cual y mantienen la proporción si cambias el tamaño.

Not your values yet? Take the test or adjust them in the playground. ¿Todavía no son tus valores? Haz la prueba o ajústalos en el probador.

Our reviewNuestra reseña

RecommendedRecomendada Reviewed version 1.14.1 (source code on GitHub), November 2026.Versión revisada: 1.14.1 (código fuente en GitHub), noviembre de 2026.

Why this one

  • The right controls. Letter spacing, word spacing and line height are separate sliders. The research says these matter more than the font, and that letter and word spacing should be adjusted together. Many extensions only swap the font for OpenDyslexic.
  • Good font choices. Andika, Lexend, Atkinson Hyperlegible Next, Shantell Sans and OpenDyslexic are built in, plus any font installed on your computer (e.g. Verdana).
  • Private. We read the code: it makes no network requests and stores settings only in your browser. Both stores list it as collecting no data. No account, no ads.
  • Light. It just sets four style values on the page and stays idle until you change something.
  • Free and open source (GPL-3.0), on Chrome, Edge, Firefox and Firefox for Android.

What we checked in the code

  • Permissions: “storage”, “scripting” and access to all http/https sites. Access to every site is needed to restyle every site and is normal for this kind of tool, but it does mean you are trusting the code. Because the code is public, anyone can check it.
  • What it changes: font, letter spacing and word spacing on text elements; line height only on paragraphs, lists, quotes and article text. Code blocks and icons are left alone by default.

Limitations

  • No text-size control — use the browser setting (step 6 above).
  • Line height does not apply to headings or to sites that build text out of generic boxes, so some pages change less than others.
  • It doesn’t work on PDFs opened in the browser or on the browser’s own pages.
  • No reading ruler, colour overlays or text-to-speech.
  • It is a small project by one developer (launched late 2025, about 480 Firefox users). The Chrome store version has lagged behind Firefox (1.9.6 vs 1.14.1 when we checked).
  • Some fonts lack Cyrillic or Greek letters; the site’s own font is used for those.

Alternatives

  • Helperbird — much more complete (fonts, spacing, colours, reading ruler, text-to-speech). Some features are paid.
  • Built into your browser: Chrome’s Reading mode, Edge’s Immersive Reader and Firefox’s Reader View let you change font, size and spacing for articles, without installing anything.

Por qué esta

  • Los controles correctos. El espacio entre letras, el espacio entre palabras y el interlineado son controles separados. La investigación indica que esto importa más que la fuente, y que el espacio entre letras y entre palabras se debe ajustar en conjunto. Muchas extensiones solo cambian la fuente a OpenDyslexic.
  • Buenas fuentes. Trae Andika, Lexend, Atkinson Hyperlegible Next, Shantell Sans y OpenDyslexic, y además cualquier fuente instalada en tu computador (por ejemplo, Verdana).
  • Privada. Leímos el código: no se conecta a internet y guarda los ajustes solo en tu navegador. Ambas tiendas la declaran sin recolección de datos. Sin cuenta y sin publicidad.
  • Liviana. Solo aplica cuatro valores de estilo a la página y queda en reposo hasta que cambias algo.
  • Gratis y de código abierto (GPL-3.0), en Chrome, Edge, Firefox y Firefox para Android.

Lo que revisamos en el código

  • Permisos: “storage”, “scripting” y acceso a todas las páginas http/https. El acceso a todas las páginas es necesario para cambiarles el estilo y es normal en este tipo de herramientas, pero implica confiar en el código. Como el código es público, cualquiera puede revisarlo.
  • Qué cambia: fuente, espacio entre letras y espacio entre palabras en los elementos de texto; el interlineado solo en párrafos, listas, citas y texto de artículos. Por defecto no toca los bloques de código ni los íconos.

Limitaciones

  • No ajusta el tamaño de letra: usa la configuración del navegador (paso 6).
  • El interlineado no se aplica a títulos ni a páginas que arman el texto con cajas genéricas, así que algunas páginas cambian menos que otras.
  • No funciona en PDF abiertos en el navegador ni en las páginas propias del navegador.
  • No tiene regla de lectura, filtros de color ni lectura en voz alta.
  • Es un proyecto pequeño de una sola persona (lanzado a fines de 2025, unos 480 usuarios en Firefox). La versión de Chrome ha ido atrasada respecto a la de Firefox (1.9.6 frente a 1.14.1 cuando la revisamos).
  • Algunas fuentes no incluyen letras cirílicas o griegas; para esas se usa la fuente original de la página.

Alternativas

  • Helperbird: mucho más completa (fuentes, espaciado, colores, regla de lectura, lectura en voz alta). Algunas funciones son pagadas.
  • Incluido en tu navegador: el Modo de lectura de Chrome, el Lector inmersivo de Edge y la Vista de lectura de Firefox permiten cambiar fuente, tamaño y espaciado en artículos sin instalar nada.
